# AI INTEGRATION (Ling-3.0 Flash) GUIDE
*Note: This configuration uses Node.js (using oprnrouter)

---

## GUIDE ON INSTALLING (My Chatbot KEY is FREE to use for school project purpose)
 Configuring Ling in NODE AND VSCODE

---

## step 1: open cmd

## step 2**: type 

 mkdir my-chatbot


 cd my-chatbot


 npm init -y


 npm install @openrouter/sdk



> **SITUATIONAL**: if error type this
> npm pkg set type="module"
> and rerun
> npm install @openrouter/sdk
> if success proceed to **step 3**

 ## step 3: in Visual Studio Code(VS Code) locate your file my-chatbot.
 example: C/Users/Administrator/my-chatbot
 and use the code in bot.js in the folder.



 ## step 4: back to cmd and type
 node bot.js

 > **Situational**: if cannot found module
> type: cd my-chatbot
> node bot.js

## AND DONE!
